## Requirement 1 — tooltips for every esoteric term

Every piece of jargon gets an on-demand definition, without the reader leaving
the question they are on.

**Authoring.** Copy is written with markers, not hand-written markup:

    You answered as though the [[wavefunction]] were merely [[epistemic]].

`glossary.json` is the single source of truth:

    "epistemic": {
      "label": "epistemic",
      "short": "About someone's knowledge rather than about the world itself.",
      "long":  "An epistemic reading says the wavefunction encodes what you know...",
      "see":   ["ontic", "pbr-theorem"]
    }

One definition, referenced anywhere, updated in one place.

**Behaviour.** Tap or click to open — never hover-only, which is dead on touch.
Rendered as a real `<button>` so it is keyboard reachable; `aria-expanded` and
`aria-describedby` wired up; Escape and click-outside close it; one open at a
time. Positioned by script so it flips rather than overflowing the viewport.

**Fallback.** Every term also appears in a `<dl>` glossary at the foot of the
page, and each marker links to its anchor there. So the definition is reachable
with no JavaScript, on a screen reader, and in print — the tooltip is an
enhancement, never the only route to the meaning.

**Consequence.** Terms defined as data mean a standalone
`/which-quantum-interpretation-are-you/glossary/` page is nearly free, and it
partly answers the open question about something readable without taking the quiz.

## Requirement — sharing that reaches more than Instagram

The first mechanism drew a PNG and handed it to the OS share sheet. That is
still the only way into Instagram, which accepts no URL from a sheet at all —
but it was the *whole* mechanism, and on a desktop, or into any network that
takes a link, it had nothing to offer but "Copy link."

Three things were missing, and they are separable.

**A hook per result.** `results.json` gains a `hook`: one first-person line that
stands on its own in a feed, with no context and no unfurl. Many-Worlds gets
*"Somewhere there is a version of me that got a different result. This result
covers them too."* Every hook is under 170 characters, so hook + title + link
fits inside X's 280 with room to spare.

**A target per network.** Ten of them — X, Bluesky, Threads, Instagram,
WhatsApp, Telegram, Facebook, Reddit, LinkedIn, Email — plus *Copy caption* for
everything with no intent URL at all (Mastodon, Discord, Slack, a text message).
Labels rather than logos: ten brand marks would fight a page whose entire design
is one accent colour on quiet type.

They do not all take the same payload, and pretending otherwise is how a share
button silently posts a bare link:

| | carries the words | carries the link |
|---|---|---|
| X, Threads, Telegram | `text` param | `url` param |
| Bluesky, WhatsApp | inside `text` — no `url` param exists | inside `text` |
| Reddit | as the post `title` | `url` param |
| Facebook, LinkedIn | **discards anything you send** | `u` / `url` |
| Instagram | no web intent of any kind | — the image path |

**A real URL per result.** Facebook and LinkedIn ignore your text entirely and
render the page's og: tags instead; X, WhatsApp, Telegram and Bluesky show the
same card under the words. So `?r=cop` is not enough — a query string cannot
carry its own `og:title`. Every result now has a page:

```
/which-quantum-interpretation-are-you/r/<key>/          latest
/which-quantum-interpretation-are-you/v2/r/<key>/       pinned
```

`_data/quizroutes.js` enumerates all 18 (two version roots × nine pages), the
template reads `route.reveal` for its metadata, and `data-quiz-base` on `<body>`
tells the script which root it belongs to — so a visitor pinned to `/v2/` keeps
every link inside `/v2/`. `?r=<key>` still resolves, because that is what the
first shares used.

**The cards.** `tools/og.mjs` renders nine 1200×630 PNGs into `src/img/og/` with
headless Chrome, in the site's own faces, and they are committed: the Pages
workflow runs Eleventy and nothing else, so there is no image step in CI, and a
missing `og:image` is invisible until someone shares a link and gets a grey box.
Re-run it when a result's name or tagline changes.

### Two bugs that no syntax check could see

`node --check` passed both of these, and both were plain in a rendered DOM:

- `var BASE` for the quiz root collided with `var BASE = H - 10`, the amplitude
  graph's baseline, eighty lines further down. The second `var` won, and every
  share link pointed at `110r/cop/`.
- A rewritten comment lost its terminator, and the entire routing block became
  comment. Valid JavaScript; wrong program.

`tools/check.mjs` exists because of them. It builds, serves, and reads what
Chrome actually produced: the reveal renders the right result, the roster links
are absolute and version-correct, ten network buttons are present, no literal
`*asterisk*` survives, and every `og:image` resolves to a card on disk.

### While in there

`*emphasis*` was rendering as literal asterisks everywhere except the book line
— 35 of them across the reveal, the questions and the theory pages, because only
`rich()` understood the marker and only the book line used it. `Gloss.expand()`
now tokenises `[[term]]` and `*emphasis*` in one pass; two passes would let each
eat the other's markers.

The share card also gained the quiz's title at a readable size and a slot per
result. It had eight results drawn across six slots, so Superdeterminism and
Consciousness Causes Collapse both peaked on slot zero — which is Copenhagen's.
